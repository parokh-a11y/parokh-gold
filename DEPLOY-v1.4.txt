=== تنظیم ایمیل در Supabase (اجباری برای بازیابی) ===
1. ورود به supabase.com → پروژه
2. Authentication → Providers → Email = ON
3. Authentication → URL Configuration:
   Site URL: https://parokh-gold.parokh.workers.dev
   Redirect URLs: https://parokh-gold.parokh.workers.dev/*
4. Authentication → Emails → قالب Reset password فعال
5. (اختیاری حرفه‌ای) Settings → Auth → SMTP: ایمیل سفارشی خودت

اگر Confirm email روشن باشد، بعد از ثبت‌نام کاربر باید لینک ایمیل را تأیید کند.

=== اگر URL پروژه Supabase فرق دارد ===
