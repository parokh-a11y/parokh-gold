REQUIRED AFTER UPLOAD:
1) Create KV namespace:
   npx wrangler kv namespace create PAROKH_KV
   Put id into wrangler.toml under [[kv_namespaces]]
2) Set secrets (rotate old ones):
   npx wrangler secret put BAN_SECRET
   npx wrangler secret put DATA_SECRET
   npx wrangler secret put ADMIN_SECRET
3) npx wrangler deploy

Admin API reads require header: x-parokh-secret: <ADMIN_SECRET or DATA_SECRET>
