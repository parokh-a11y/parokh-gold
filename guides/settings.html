Inputs Settings

مرجع Inputs نسخه فعلی PAROKH GOLD EA (V9.76). مقادیر پیش‌فرض نقطه شروع هستند؛ با ریسک خودتان تنظیم کنید. سود تضمینی وجود ندارد.

۱. حجم پوزیشن (Position Volume)

  • LotSizePerClick — مجموع لات با هر کلیک BUY یا SELL (هر دو حالت حجم).
  • VolumeMode — NORMAL = تقسیم مساوی لات · SMART = وزن‌دهی هوشمند بین پوزیشن‌ها.
  • PositionCount — تعداد پوزیشن در هر کلیک (۱ تا ۵).
  • PartialClosePercent — درصد بسته شدن هر پوزیشن با دکمه‌های Partial.

۲. Stop Loss

  • UseStopLoss — قرار دادن SL روی پوزیشن‌های تازه‌باز.
  • StopLossDollars — فاصله SL به واحد پول حساب (دلار).

۳. سطوح Take Profit

  • TakeProfit1Dollars … TakeProfit5Dollars — هدف هر سطح TP به دلار حساب (پیش‌فرض ۵ / ۱۰ / ۱۵ / ۲۰ / ۵۰).

۴. Trailing و Breakeven

  • EnableGroupBreakeven — بعد از بسته شدن واقعی TP1 با سود، SL باقی‌مانده‌ها را نزدیک سربه‌سر قفل می‌کند (اولویت گروه).
  • GroupBE_MinProfit — بسته‌شدن‌های زیر این مبلغ (مثلاً TP-to-Entry) برای Group BE نادیده گرفته می‌شوند.
  • EnableTrailing — تریلینگ دستی همیشه، یا خودکار بعد از بسته شدن سوددار TP3.
  • TrailingStart / TrailingStep — شروع و گام تریلینگ به دلار.
  • EnableBreakeven — BE کلاسیک؛ دستی یا خودکار بعد از سود TP2.
  • BreakevenAfter / BreakevenPlus — فعال‌سازی پس از سود مشخص و قفل کمی بالاتر از ورود.

۵. سفارش دستی

  • ManualOrder_UseSmartVolume — پنل دستی از همان VolumeMode برای تقسیم حجم استفاده کند.

۶. سقف ریسک و ایمنی

  • EnableMaxVolumeOneDir / MaxVolumeOneDirection — سقف مجموع لات باز در یک جهت (Buy یا Sell).
  • EnableDailyRiskLimits — محدودیت روزانه ضرر/هدف.
  • DailyLimitMode — حالت درصد از بالانس یا مبلغ ثابت دلار.
  • DailyDrawdownPercent / DailyTargetPercent — سقف ضرر و هدف روزانه در حالت درصد.
  • DailyDrawdownFixed / DailyTargetFixed — همان‌ها به دلار ثابت.
  • ProtectDangerousButtons — تأیید قبل از REVERSE / RESET / CLOSE ALL / REMOVE / HEDGE.

۷. زبان Tooltip

  • PanelLanguage — فقط زبان راهنمای موس و پیام‌ها (FA/EN)؛ متن دکمه‌های پنل انگلیسی می‌ماند.
  • ShowTooltips — نمایش Tooltip با بردن موس روی دکمه.

۸. هشدار و هویت

  • EnableAlerts — هشدار اختیاری رویداد معامله (نه انقضای لایسنس).
  • MagicNumber — مجیک برای جداسازی پوزیشن‌های این اکسپرت.

لایسنس و دمو (یادداشت محصول)

  • فایل رسمی LockedPro + لایسنس آنلاین روی یک حساب MT5 (Account + Broker + Server).
  • در MT5: Tools → Options → Expert Advisors → Allow WebRequest برای دامنه سرور لایسنس.
  • نسخه Demo: آزمایش حدود ۷ روز از اولین اجرا روی همان ترمینال؛ فقط حساب دمو.

Inputs reference for the current PAROKH GOLD EA (V9.76). Defaults are a starting point only — tune to your own risk. No profit guarantee.

1. Position Volume

  • LotSizePerClick — Total lots per BUY/SELL click (both volume modes).
  • VolumeMode — NORMAL = equal split · SMART = weighted lots across positions.
  • PositionCount — Positions per click (1–5).
  • PartialClosePercent — Percent closed by Partial buttons on each position.

2. Stop Loss

  • UseStopLoss — Place SL on newly opened positions.
  • StopLossDollars — SL distance in account currency ($).

3. Take Profit Levels

  • TakeProfit1Dollars … TakeProfit5Dollars — TP targets in account $ (defaults 5 / 10 / 15 / 20 / 50).

4. Trailing & Breakeven

  • EnableGroupBreakeven — After a real profitable TP1 close, lock remaining SL near break-even (group priority).
  • GroupBE_MinProfit — Ignore closes below this $ (e.g. TP-to-Entry) for Group BE.
  • EnableTrailing — Manual ON always, or auto after a profitable TP3 close.
  • TrailingStart / TrailingStep — Start and step distance in $.
  • EnableBreakeven — Classic BE; manual or auto after TP2 profit.
  • BreakevenAfter / BreakevenPlus — Trigger after set profit; lock slightly above entry.

5. Manual Orders

  • ManualOrder_UseSmartVolume — Manual panel uses the same VolumeMode split.

6. Risk Limits & Safety

  • EnableMaxVolumeOneDir / MaxVolumeOneDirection — Cap open lots in one direction.
  • EnableDailyRiskLimits — Daily drawdown / target block.
  • DailyLimitMode — Percent of balance or fixed $.
  • DailyDrawdownPercent / DailyTargetPercent — Daily loss/profit caps in percent mode.
  • DailyDrawdownFixed / DailyTargetFixed — Same limits in fixed $.
  • ProtectDangerousButtons — Confirm before REVERSE / RESET / CLOSE ALL / REMOVE / HEDGE.

7. Tooltips Language

  • PanelLanguage — Tooltips/messages FA or EN (panel button labels stay English).
  • ShowTooltips — Show tooltips on hover.

8. Alerts & Identity

  • EnableAlerts — Optional trade-event alerts (not license expiry).
  • MagicNumber — Magic for this EA’s positions/orders.

License & Demo (product notes)

  • Official LockedPro file + online license for one MT5 account (Account + Broker + Server).
  • In MT5 allow WebRequest for the license server domain.
  • Demo: about 7 days from first run on that terminal; DEMO accounts only.
