1) npx wrangler secret put RESEND_API_KEY
   (same key as sales bot if you already use Resend)
2) Optional:
   npx wrangler secret put RESEND_FROM
   value example: PAROKH GOLD Support <support@parokh.ir>
   npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
3) npx wrangler deploy
4) Set Telegram webhook once (replace TOKEN and optional secret):
   https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://parokh-gold.parokh.workers.dev/api/telegram/webhook
   If TELEGRAM_WEBHOOK_SECRET set, use:
   .../setWebhook?url=https://parokh-gold.parokh.workers.dev/api/telegram/webhook?secret=YOUR_SECRET
