v1.20 SECURITY

1) Create KV and bind in wrangler.toml
   npx wrangler kv namespace create PAROKH_KV

2) Set secrets:
   npx wrangler secret put ADMIN_USER
   npx wrangler secret put ADMIN_PASS
   npx wrangler secret put ADMIN_SECRET
   (optional) DATA_SECRET BAN_SECRET PAYMENT_ADDRESS_TRC20

3) npx wrangler deploy

Admin login:
- POST /api/admin/login with {user, pass}
- Returns signed token (8h)
- All admin APIs need header: x-parokh-admin: <token>
- NO password in frontend source

Orders:
- ID generated server-side
- Price from server PLAN_PRICES only

APIs bans/orders GET/license-requests GET require admin token.
