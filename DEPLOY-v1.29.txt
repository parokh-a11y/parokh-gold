PAROKH GOLD v1.29 — Support hub + Telegram notify

1) Deploy site
   npx wrangler deploy

2) Telegram notify secrets (site Worker)
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put ADMIN_CHAT_ID

   TELEGRAM_BOT_TOKEN = token from @BotFather (same bot as support bot is OK)
   ADMIN_CHAT_ID = your numeric Telegram chat id

3) Create email support@parokh.ir (Cloudflare)
   Cloudflare Dashboard → parokh.ir → Email → Email Routing
   → Enable Email Routing
   → Destination addresses → add your personal Gmail → verify
   → Routing rules → Create address:
        support@parokh.ir  →  forward to your Gmail
   (Optional later: Email Worker to also POST into /api/support for Telegram)

4) Test
   Open /support.html → send form → check Telegram admin chat
   Open admin → Support Tickets
